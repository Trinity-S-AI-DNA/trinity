An error message split into its four parts, in the order you read them, and where to start reading. Lesson 6 of the vibecoding course.

What to do with an error

  1. Read the message whole
  2. Open the file at the line
  3. Read from one line above
  4. Fix one thing and run again

The four parts of an error message
PartWhat it tells you
Kindthe family of the problem, such as a syntax error
Messagewhat the program says went wrong, in its own words
Filewhich file to open
Linewhere it was noticed; the cause can sit just above

The example parts are generic wording, not output of a run; paste your own whole message to your agent.
