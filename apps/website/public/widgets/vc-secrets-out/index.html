A message to an agent

Read the bot's token from the setting named BOT_TOKEN. The value is in my .env file; do not print it.

Never paste the value itself into a message: a message can be logged, shared or saved.

In .env.example the setting holds only a made-up placeholder:

BOT_TOKEN=your-token-goes-here

This page runs no script, sets no cookie and sends nothing anywhere.
