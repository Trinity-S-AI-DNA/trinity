Vibecoding 5: ten terminal commands

Ten terminal commands that cover a first day, each with a one-line meaning, and the one that cannot be undone. Lesson 5 of the vibecoding course.

The ten commands How each one runs

Every command works the same way

  1. Type the command
  2. Press Enter
  3. Read what it prints
  4. Type the next one

The ten commands How each one runs

Ten terminal commands
CommandWhat it does
pwdprint the folder you are in
lslist what is in this folder
cdchange to another folder
mkdirmake a new folder
touchmake a new empty file
catprint a file's text
cpcopy a file
mvmove or rename a file
rmdelete a file with no undo
clearwipe the screen, keep your files

Read rm twice before you press Enter: a deleted file does not go to a trash can.

This page runs no script, sets no cookie and sends nothing anywhere.
