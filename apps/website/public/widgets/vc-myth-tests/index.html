Vibecoding 3: five myths, each put to a test

Five sentences that sound right about vibecoding, each settled by a small case a test can run. Lesson 3 of the vibecoding course.

Five myths A test, step by step

How a myth is put to a test

  1. Say the myth as a sentence
  2. Find a small case where it could fail
  3. Write the check with the answer you expect
  4. Run it and read the verdict

Five myths A test, step by step

Five myths and the case that settles each
MythWhat the test found
If it runs without an error, it is right.average of 4 and 8 printed 8, the answer is 6
One passing test proves the code is right.x * x equals x + x at 2 and not at 3
The agent remembers the whole conversation.8 messages kept of 20 sent
A step you do can always be undone.7 halved and doubled is 6, not 7
A check that passes is a good check.a check that says yes to 2 against 3 cannot fail

The cases are small on purpose: each fits in one line you can check by hand.
