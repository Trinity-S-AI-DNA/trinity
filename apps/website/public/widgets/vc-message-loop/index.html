A bot is a loop: send messages, watch it answer

Send start, help or an unknown word to a toy bot and watch the four beats of its message loop: wait, read, reply, wait again. A stop message ends it. Nothing is sent.

  1. Wait for a message
  2. Read it
  3. Pick the reply from the table
  4. Send the reply

What the bot answered

Turn 1: you sent blah

The bot says: I did not understand that.

Send a message to the bot

blah start help stop Start the loop again
