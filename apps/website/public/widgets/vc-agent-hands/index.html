Three tools, which run at once and which wait for a yes, and the cap on calls in one turn. Lesson 20 of the Vibecoding from zero course.

The three tools How a call runs

One tool call

  1. The agent names a tool
  2. The host checks the list
  3. A write waits for a yes
  4. The host runs the tool
  5. The result goes back as text
