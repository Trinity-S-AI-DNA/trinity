T27F live

A recorded log of agent events — spawns, delivers, crashes — replayed through work_graph.t27, which joins each event into one work graph, and hud.t27, which reads that graph into a HUD scene: one task card per node plus a status bar. Both run here as WebAssembly, the same t27f.wasm build as the graph view. A card names its node's kind, id and provenance label; dashed outlines mark labels weaker than exact; a refused event stops the replay, never truncates it. The recording is work_graph_fixture.t27's 1,024 events, the same feed the spec's own tests replay. See PROVENANCE.txt for the exact sources, compiler and checksums.
