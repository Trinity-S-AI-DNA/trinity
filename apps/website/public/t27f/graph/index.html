T27F graph view

One box per node, one line per edge of a .t27 spec. The graph is read from the spec's bytes by spec_graph_export.t27; the placement, size and colour of every box come from spec_graph_view.t27. Both run here as WebAssembly. A box shows its kind, name, inference label (exact, derived, suggested, unknown) and source lines; dashed outlines mark labels weaker than exact. A spec over the graph's cap is refused, never drawn truncated. See PROVENANCE.txt for the exact sources, compiler and checksums.
